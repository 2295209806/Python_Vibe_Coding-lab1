# 需求澄清清单
## 考题一：Excel 报表生成脚本
### 目标
编写Python脚本自动化完成销售原始Excel数据的清洗、多维度统计，并输出标准化报表Excel文件。
### 输入
- 输入文件：sales_raw.xlsx
- 字段：日期、销售员、产品、数量、单价、地区
- 数据问题：存在空值、重复行、负数量等脏数据
### 输出
- 输出文件：report.xlsx
- 包含4个工作表：
  1. 明细清洗后：清洗完成的完整明细数据，新增销售额字段
  2. 按销售员：各销售员销售额汇总
  3. 按地区：各地区销售额汇总
  4. 总览：月度销售总额
### 边界与约束
1. 禁止修改原始输入文件
2. 关键字段（日期、销售员、产品、数量、单价、地区）缺失的行需删除
3. 数量≤0的行判定为异常数据，需剔除
4. 全字段完全重复的行需去重
5. 异常场景必须给出明确可读的错误提示：
   - 输入文件不存在
   - 输入文件为空/无法读取
   - 缺少必要字段
   - 清洗后无有效数据
### 验收标准
1. 样例数据下一键运行生成report.xlsx
2. 统计结果与人工计算一致
3. 异常输入不崩溃，返回清晰错误信息

## 考题二：FastAPI 记账接口
### 目标
实现一个支持增、查、统计的HTTP记账服务，具备参数校验、筛选分页、汇总统计能力。
### 输入输出
1. 新增流水：POST /records
   - 输入：金额、类型（收入/支出）、分类、日期
   - 输出：新增成功的记录信息
2. 查询流水：GET /records
   - 输入：类型、分类、日期区间（可选筛选条件）、分页参数
   - 输出：分页后的流水列表+总数
3. 统计汇总：GET /summary
   - 输入：日期区间
   - 输出：收入合计、支出合计、结余
### 边界与约束
1. 金额必须>0，类型只能是「收入」或「支出」，日期格式为YYYY-MM-DD
2. 非法参数返回4xx状态码+结构化错误信息
3. 数据存储使用SQLite，保证并发写入数据一致性
4. 支持分页查询，默认分页参数可配置
### 验收标准
1. 服务可正常启动，接口可调用
2. 参数校验用例返回预期状态码和错误信息
3. pytest覆盖核心业务用例
4. 并发写入无数据错误
